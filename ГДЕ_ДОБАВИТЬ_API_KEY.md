# 🔑 Где добавить OnchainKit API Key

## 🎯 КУДА: В переменные окружения Vercel

API ключ нужно добавить в **Vercel Dashboard** в разделе **Environment Variables**.

---

## 📍 ШАГ ЗА ШАГОМ:

### ШАГ 1: Откройте Vercel Dashboard

👉 **Перейдите**: https://vercel.com/dashboard

1. Войдите в свой аккаунт Vercel
2. Найдите проект `seer-base1` или `seerbase1`
3. **Кликните** на проект чтобы открыть

---

### ШАГ 2: Откройте Settings

1. В левом меню найдите **"Settings"**
2. **Кликните** на "Settings"

---

### ШАГ 3: Откройте Environment Variables

1. В меню Settings найдите **"Environment Variables"**
2. **Кликните** на "Environment Variables"

Вы увидите список переменных окружения (может быть пустым).

---

### ШАГ 4: Добавьте API Key

1. Нажмите кнопку **"Add New"** или **"Add"** (обычно справа вверху)

2. Заполните форму:

   **Key (Имя переменной):**
   ```
   NEXT_PUBLIC_ONCHAINKIT_API_KEY
   ```
   ⚠️ **ВАЖНО:** Название должно быть **ТОЧНО** таким (копируйте!)

   **Value (Значение):**
   ```
   ваш_api_key_здесь
   ```
   Вставьте скопированный API Key из Coinbase Developer Platform

   **Environment (Окружение):**
   Выберите:
   - ✅ **Production** (для продакшена)
   - ✅ **Preview** (для preview деплоев)
   - ✅ **Development** (для локальной разработки)

   Или выберите **"All"** чтобы применить ко всем окружениям.

3. Нажмите **"Save"** или **"Add"**

---

### ШАГ 5: Добавьте NEXT_PUBLIC_URL (если еще нет)

Пока вы в разделе Environment Variables, добавьте еще одну переменную:

1. Нажмите **"Add New"** еще раз

2. Заполните:

   **Key:**
   ```
   NEXT_PUBLIC_URL
   ```

   **Value:**
   ```
   https://seerbase1-alekseys-projects-ca98dec1.vercel.app
   ```
   (Ваш Vercel URL, БЕЗ слеша в конце)

   **Environment:**
   Выберите **Production** или **All**

3. Нажмите **"Save"**

---

### ШАГ 6: Передеплойте проект

После добавления переменных нужно передеплоить:

1. Перейдите в **"Deployments"** (верхнее меню)
2. Найдите последний деплой
3. Нажмите **⋮** (три точки справа)
4. Выберите **"Redeploy"**
5. Подтвердите **"Redeploy"**

⏱️ Подождите 2-3 минуты пока задеплоится

---

## 🔑 ГДЕ ВЗЯТЬ API KEY:

Если у вас еще нет API Key:

1. Откройте: https://portal.cdp.coinbase.com/
2. Войдите через Coinbase
3. Создайте новый проект или выберите существующий
4. Найдите раздел **"API Keys"** или **"Client API Key"**
5. Скопируйте ключ (начинается с `cb_`)
