# 🔍 Проверка: Нужна ли подпись манифеста?

## 🎯 Давайте проверим что реально нужно

У вас уже есть оба варианта в коде!

---

## ✅ В вашем `minikit.config.ts` уже есть:

### 1. accountAssociation (пустой - для старого процесса)
```typescript
accountAssociation: {
  header: "",
  payload: "",
  signature: ""
},
```

### 2. baseBuilder (заполненный - для нового процесса)
```typescript
baseBuilder: {
  ownerAddress: "0xeCF05e29657A0f2242796E803E3e59538dE56526"
}
```

---

## 🧪 ТЕСТ: Проверьте что показывает base.dev/preview

### Шаг 1: Откройте Preview Tool

👉 https://www.base.dev/preview?tab=account

### Шаг 2: Что вы там видите?

#### Вариант А: Кнопка "Import" + baseBuilder инструкция

**Если видите это:**

```
Add your Base Account address to farcaster.json

This verifies your mini app ownership...

{
  "accountAssociation": { ... },
  "miniapp": { ... },
  "baseBuilder": {
    "ownerAddress": "0x..."
  }
}

[App URL input field]
```

**Значит:**
- ✅ Используется НОВЫЙ процесс
- ✅ baseBuilder уже добавлен в код
- ✅ **Подпись НЕ нужна!**
- ✅ Просто введите URL и нажмите Submit

---

#### Вариант Б: Кнопка "Verify" + инструкция про подпись

**Если видите это:**

```
Sign your manifest

Connect your Farcaster wallet to verify...

[Verify Button]
```

**Значит:**
- 📝 Используется СТАРЫЙ процесс
- 📝 Нужно подписать манифест
- 📝 Скопировать accountAssociation
- 📝 Обновить код

---

## 🎯 ЧТО ДЕЛАТЬ В КАЖДОМ СЛУЧАЕ:

### ✅ Если видите "Import" (НОВЫЙ процесс):

1. Введите ваш Vercel URL (без https://)
2. Нажмите Submit/Import
3. **Готово!** Никакой подписи не требуется
4. baseBuilder уже в коде

**Переходите к публикации в Base App!**

---

### 📝 Если видите "Verify" (СТАРЫЙ процесс):

Тогда нужно подписать:

1. На странице https://www.base.dev/preview?tab=account
2. Нажмите **"Verify"**
3. Подключите Farcaster кошелек (Warpcast)
4. Подпишите транзакцию
5. Скопируйте появившийся объект:
   ```json
   {
     "header": "eyJmaWQiOjE3MzE4...",
     "payload": "eyJkb21haW4iOi...",
     "signature": "MHhmNGQzN2M2OTk4..."
   }
   ```

6. Откройте `minikit.config.ts`
7. Замените пустые значения:
   ```typescript
   accountAssociation: {
     header: "скопированный_header",
     payload: "скопированный_payload",
     signature: "скопированная_signature"
   },
   ```

8. Сохраните и закоммитьте:
   ```bash
   git add minikit.config.ts
   git commit -m "feat: add account association signature"
   git push origin main
   ```

---

## 🔍 КАК УЗНАТЬ ЧТО У ВАС?

### Простой тест:

1. Откройте https://www.base.dev/preview?tab=account
2. Посмотрите на кнопку:

   - **"Verify"** = старый процесс (нужна подпись)
