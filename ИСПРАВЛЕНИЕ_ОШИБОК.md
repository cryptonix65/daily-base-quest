## 🚀 ШАГ 1: Установите NEXT_PUBLIC_URL в Vercel

### 1.1 Откройте Vercel Dashboard

1. Перейдите на https://vercel.com/dashboard
2. Найдите проект `seer-base1` или `seerbase1`
3. Откройте проект

### 1.2 Добавьте переменную окружения

1. Перейдите в **Settings** (слева в меню)
2. Нажмите **Environment Variables**
3. Найдите или добавьте переменную:

```
Name:  NEXT_PUBLIC_URL
Value: https://seerbase1-alekseys-projects-ca98dec1.vercel.app
```

**ВАЖНО:** 
- ✅ Используйте **полный URL** с `https://`
- ✅ **БЕЗ** слеша в конце (`/`)
- ✅ Точно такой же как в вашем браузере

### 1.3 Сохраните и передеплойте

1. Нажмите **"Save"**
2. Перейдите в **Deployments** (верхнее меню)
3. Найдите последний деплой
4. Нажмите **⋮** (три точки)
5. Выберите **"Redeploy"**
6. Подтвердите **"Redeploy"**

⏱️ Подождите 2-3 минуты пока задеплоится

## 🔐 ШАГ 4: Исправление "failed to validate project ownership"

### 4.1 Проверьте baseBuilder

Убедитесь что в манифесте (из Шага 2) есть:

```json
"baseBuilder": {
  "ownerAddress": "0x476a4bd984714e970Eb8330Bc46A52469C0A57Dd"
}
```

### 4.2 Проверьте что адрес совпадает

На странице base.dev/preview должен отображаться тот же адрес:
```
0x476a...57Dd
```

### 4.3 Если адреса не совпадают

Если на base.dev/preview показывается другой адрес:

1. Скопируйте адрес который показывает base.dev
2. Откройте `minikit.config.ts`
3. Обновите `baseBuilder.ownerAddress` на этот адрес
4. Закоммитьте и запушьте:
   ```bash
   git add minikit.config.ts
   git commit -m "fix: update baseBuilder ownerAddress"
   git push origin main
   ```
5. Подождите пока Vercel задеплоит (2-3 минуты)
6. Попробуйте снова

## 🆘 ЕСЛИ ВСЕ ЕЩЕ НЕ РАБОТАЕТ

### Проблема: Манифест все еще не найден

**Решение:**
1. Проверьте что файл `app/.well-known/farcaster.json/route.ts` существует
2. Убедитесь что проект правильно задеплоен
3. Проверьте логи в Vercel Dashboard → Deployments → последний деплой → Functions

### Проблема: Все еще "failed to validate project ownership"

**Решение:**
1. Убедитесь что вы вошли на base.dev/preview через **keys.coinbase**
2. Проверьте что адрес в baseBuilder совпадает с адресом который показывает base.dev
3. Попробуйте выйти и войти снова на base.dev/preview

### Проблема: URL в манифесте неправильные

**Решение:**
1. Убедитесь что NEXT_PUBLIC_URL установлен правильно
2. Передеплойте проект
3. Проверьте манифест снова
