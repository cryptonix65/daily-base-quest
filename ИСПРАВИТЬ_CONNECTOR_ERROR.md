# 🔧 Исправление ошибки "Connector not connected"

## ❌ Проблема:

Ошибка: **"Connector not connected. Version: @wagmi/core@2.21.0"**

Это означает что wagmi не видит подключенный кошелек в MiniKit окружении.

---

## ✅ ЧТО Я ИСПРАВИЛ:

1. ✅ Заменил `useWriteContract` на `useSendTransaction`
2. ✅ Добавил проверку подключения кошелька через `useAccount`
3. ✅ Добавил сообщение об ошибке если кошелек не подключен

---

## 🔍 ПРИЧИНЫ ОШИБКИ:

### 1. Кошелек не подключен автоматически

В MiniKit приложениях кошелек должен подключаться автоматически через `autoConnect: true`, но иногда это не работает сразу.

### 2. Wagmi не видит MiniKit connector

Wagmi может не распознавать MiniKit connector как стандартный wagmi connector.

---

## ✅ РЕШЕНИЯ:

### РЕШЕНИЕ 1: Подождите подключения (самое простое)

В Base App кошелек должен подключиться автоматически:

1. **Откройте приложение в Base App** (не в обычном браузере)
2. **Подождите 2-3 секунды** - кошелек должен подключиться автоматически
3. Ошибка должна исчезнуть

---

### РЕШЕНИЕ 2: Проверьте что вы в Base App

**Важно:** Приложение должно открываться **внутри Base App**, а не в обычном браузере!

1. Откройте **Base App** (мобильное приложение)
2. Найдите ваш пост с приложением
3. Нажмите **"Launch"**
4. Приложение откроется внутри Base App
5. Кошелек подключится автоматически

---

### РЕШЕНИЕ 3: Если ошибка осталась

Если после исправлений ошибка все еще появляется:

#### Вариант А: Проверьте настройки rootProvider

Убедитесь что в `app/rootProvider.tsx`:

```typescript
miniKit={{
  enabled: true,
  autoConnect: true,  // ← Должно быть true
  notificationProxyUrl: undefined,
}}
```

#### Вариант Б: Добавьте явную проверку

В `app/page.tsx` уже добавлена проверка:

```typescript
if (!isConnected || !address) {
  setPaymentError("Please connect your wallet first...");
  return;
}
```

Это покажет понятное сообщение если кошелек не подключен.
